# 🏥 MediGuard

## 🎯 Hackathon Project - Landing Page

**MediGuard** - Your Health, Intelligently Protected

A stunning, modern landing page for a revolutionary healthcare platform that centralizes patient medical records, streamlines prescription handling, and enables data-driven disease monitoring through smart health intelligence.

## ✨ Features

### 🎨 Premium Design Elements
- **Animated Background Particles** - Dynamic particle system for visual depth
- **Gradient Hero Section** - Eye-catching hero with parallax effects
- **High-Quality Medical Images** - Professional Unsplash imagery
- **Floating Cards** - Animated floating information cards
- **3D Card Effects** - Portal cards with perspective transforms
- **Smooth Animations** - Framer Motion powered interactions
- **Custom Scrollbar** - Branded scrollbar design
- **Responsive Layout** - Mobile-first, fully responsive design

### 🚀 Portal Access
1. **Patient Portal** - Access medical history via Smart Health Card
2. **Doctor Portal** - Manage patient records and prescriptions
3. **Admin/Health Officer Portal** - Disease surveillance and analytics
4. **Laboratory Portal** - Test results and reporting

### 🎭 Visual Highlights
- Dark gradient hero with overlay effects
- Real medical imagery from Unsplash
- Animated statistics section
- Feature showcase with image grid
- Interactive hover effects
- Glassmorphism UI elements
- Professional color palette (Teal/Green healthcare theme)

## 🛠️ Tech Stack

- **React** - UI Framework
- **React Router** - Navigation
- **Framer Motion** - Advanced animations
- **Lucide React** - Modern icon library
- **Vite** - Build tool
- **Google Fonts (Inter)** - Typography

## 🚀 Getting Started

### Installation
```bash
npm install
```

### Development Server
```bash
npm run dev
```
Visit: `http://localhost:5173/`

### Build for Production
```bash
npm run build
```
